## 🧠 Key Learnings

- NumPy arrays make numerical operations easier and more efficient.
- Array shape tells us the structure of an array.
- The `dtype` attribute identifies the data type of elements.
- The `reshape()` method changes array dimensions without changing the total number of elements.
- Indexing and slicing help access specific data.
- Boolean filtering allows us to select data based on conditions.
- NumPy can perform mathematical operations directly on entire arrays.
